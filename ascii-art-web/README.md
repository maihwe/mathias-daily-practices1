# ASCII Art Web

## Description
The ascii-art-web project is a Go web application that lets users type text into a form on a webpage and then generates ASCII art using a chosen banner style. It is the web version of the ASCII art generator.

## Authors
Ihwe Mathias

## Usage
- Start the server with `go run .`
- Open your browser at `http://localhost:8080`
- Enter your text and select a banner style in the form
- Submit to see the ASCII art displayed on the page

## Implementation Details
1. User enters text and chooses a banner style in the form.
2. Browser sends a POST request to the Go server.
3. Server validates input and loads the correct banner file.
4. ASCII art is generated by mapping characters to their stylized representation.
5. Response returned: the server shows the ASCII art (or an error message) in the browser.
